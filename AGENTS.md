# AGENTS.md

Laravel 13 (PHP 8.3) + Inertia 3 + React 19 + TypeScript + Tailwind 4 POS application. Auth is Fortify (passkeys, 2FA); UI is shadcn/ui (new-york). Built on the `laravel/react-starter-kit` skeleton.

## Commands

Composer scripts are the source of truth; run checks through them, not raw tools.

- `composer dev` — runs `artisan serve` + `queue:listen` + `npm run dev` together (also starts Vite/Wayfinder codegen)
- `composer test` — `config:clear` + Pint check + PHPStan + Pest tests
- `composer lint` / `composer lint:check` — Pint (fix / check only)
- `composer types:check` — PHPStan, level 7 (paths include `routes/`, `config/`, `database/`)
- `composer ci:check` — npm `lint:check` + `format:check` + `types:check` + `@test` (CI runs this)
- `composer setup` — full install from scratch (creates `.env`, key, migrations, npm install + build)
- Single test: `php artisan test --filter=TestName` (Pest 5; PHPUnit runs in-memory SQLite per `phpunit.xml`)
- Frontend only: `npm run lint`, `npm run format`, `npm run types:check` (tsc), `npm run build`

## Generated code — do not edit

`resources/js/routes/`, `resources/js/actions/`, `resources/js/wayfinder/` are gitignored and regenerated by `@laravel/vite-plugin-wayfinder` whenever Vite runs (`vite.config.ts` sets `formVariants: true`). They don't exist until you run `npm run dev`/`build`. ESLint ignores them, so lint won't catch missing codegen. After changing `routes/*.php`, restart Vite to regenerate.

## Laravel conventions (differ from defaults)

- Models use the new attribute syntax instead of `$fillable`/`$casts` properties: `#[Fillable([...])]` and `protected function cast(): array` (see `app/Models/Product.php`, `Sale.php`). Follow this for new models.
- Controllers are plain (not invokable/form request) and return `RedirectResponse` or `Inertia::render(...)`.
- `routes/settings.php` is required from `routes/web.php`; keep app routes in `web.php`.
- Fortify behavior lives in `app/Actions/Fortify/` and `app/Providers/FortifyServiceProvider.php`.

## Frontend conventions

- `@/*` maps to `resources/js/*` (tsconfig). Components in `pages/<feature>/`, shared UI in `components/ui/` (shadcn).
- Tailwind 4 is CSS-first: theme is configured in `resources/css/app.css`, **there is no `tailwind.config.js`**.
- React Compiler is enabled via `babel-plugin-react-compiler` in `vite.config.ts` — components must obey compiler rules (no hooks in conditionals/loops, no mutating props/state).
- ESLint enforces: `import/order` (alphabetical groups), `consistent-type-imports` (separate type imports), blank lines around control statements, `1tbs` braces, Prettier formatting. `@typescript-eslint/no-explicit-any` is off.
- `npm install` runs with `ignore-scripts=true` (`.npmrc`).

## Domain notes

- Checkout (`CheckoutController::store`) runs in a `DB::transaction` with `lockForUpdate()` per product and decrements stock; sale items snapshot `product_name`/`unit_price` at sale time. `SaleItem` uses table `sales_items`.
- Money fields are `decimal:2` casts; keep prices/quantities as strings/decimals on the wire, not floats.
- Products/categories are resource routes minus `create`/`show`/`edit` — only `index`/`store`/`update`/`destroy`; forms are on-page components (e.g. `pages/products/product-form.tsx`).

## Environment / CI

- Default DB is SQLite (`database/database.sqlite`); session, queue, and cache stores use the `database` driver in `.env.example`.
- CI (`.github/workflows/tests.yml`): PHP 8.3 + Node 22, runs `composer setup` then `composer ci:check` on push to `main` and PRs.
- `laravel/boost` is enabled (`boost.json` lists guidelines, MCP, and dev skills); after `composer update`, `boost:update` runs automatically.
